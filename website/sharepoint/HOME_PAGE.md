## Page formatting

| Area | SharePoint section and web part | Formatting |
| --- | --- | --- |
| Title area | Full-width page title area | Background: midnight blue `#010469`; title: white, page-title style; overline: bold, all caps, gold or sky accent. |
| Award title lockup | One-column Image web part | Centered horizontal SVG at 500-620 px wide; no crop; 32 px space below. |
| Introduction and actions | One-column Text, then two Button web parts | Heading uses Heading 1; body uses Normal text; center align this area. Primary button filled; secondary button outline. |
| Statistics | Three-column section, one Text web part per column | Center align. Number is Heading 2 in gold/accent; label is Normal text in white or dark gray depending on the section background. |
| Value and category cards | Three-column sections | Use Heading 2 for each card title, Normal text for the detail, and bold accent text for the status. Use a soft/neutral background behind the category section. |
| Dates | One-column Text web part | Use Heading 1 for `Key Dates`; use a three-column table. Bold the date column and use sky/nave accent text where the theme allows. |
| Final call to action | Full-width, one-column section | Midnight-blue background; white Heading 1 and body text; centered gold/primary filled button. |
