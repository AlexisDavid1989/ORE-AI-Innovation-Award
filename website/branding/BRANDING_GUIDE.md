# ORE AI Innovation Award 2026 - Branding Guide

## Visual Identity Overview

The ORE AI Innovation Award celebrates practical AI creations with real impact. The brand should feel:
- Premium, but not stiff
- Technical, but human
- Bold, but simple

The new direction replaces generic trophy visuals with one distinctive compass-led mark that represents:
- ORE as a seal of quality
- AI as connected intelligence
- Award status as a high-trust signal

## Core Creative Direction

### Concept: Compass Instrument

The mark combines:
- An ORE-inspired ring with two diagonal openings
- A thin directional needle on the same diagonal axis
- A subtle compass rose and inner calibration circles
- Four directional arrows with measured tick marks between them

This gives the identity a clearer link to navigation, precision, markets, and technical craft.

### Style Principles

- Keep the symbol circular, measured, and symmetrical.
- Let the gold ring and needle lead; supporting calibration details stay secondary.
- Use depth lightly.
- Prioritize legibility over ornament.

## Logo System

### Included Variants
1. Full Logo: symbol + stacked wordmark
2. Horizontal Logo: symbol + one-line wordmark
3. Icon: symbol only
4. Monochrome: single-ink production use
5. Dark Theme: optimized for dark surfaces

### Usage Rules

| Context | Asset |
|---|---|
| Website header | horizontal logo |
| Email banner | horizontal logo |
| Certificate masthead | full logo |
| Favicon or app icon | icon logo |
| Print one-color | monochrome logo |
| Dark slides | dark-theme logo |

### Clear Space and Minimum Size
- Clear space: at least the width of one outer arrow around the mark
- Digital minimum: 96px width (horizontal), 40px width (icon)
- Print minimum: 24mm width (horizontal), 12mm width (icon)

## Do and Don't

### Do
- Keep the compass ring openings on the approved diagonal.
- Keep the needle thin.
- Use deep blue text on light backgrounds.
- Reserve bright gold for emphasis and recognition moments.

### Don't
- Rebuild the mark as a generic trophy or abstract badge.
- Make the compass rose stronger than the main ring.
- Add extra text or labels inside the symbol.
- Compress or stretch the logo lockups.

## Quick Implementation Notes

- For modern digital touchpoints, use the horizontal logo.
- For ceremonial materials, use the full stacked logo.
- If in doubt, reduce decorative elements before reducing whitespace.
