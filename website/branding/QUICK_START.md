# ORE AI Innovation Award 2026 - Quick Start

## 10-Minute Setup

### 1. Pick the Right Logo

| Use Case | File |
|---|---|
| Email header or website nav | logos/ore-ai-awards-horizontal.svg |
| Certificate title area | logos/ore-ai-awards-full-logo.svg |
| Favicon or social avatar | logos/ore-ai-awards-icon.svg |
| One-color print | logos/ore-ai-awards-monochrome.svg |
| One-color on dark backgrounds | logos/ore-ai-awards-monochrome-white.svg |
| Dark background slides | logos/ore-ai-awards-dark-theme.svg |

### 2. Apply Brand Colors

- Deep Blue: #1A2E4A (base)
- Gold: #D4AF37 (highlights)
- Purple: #6B5B95 (small AI accents)

Keep color usage simple:
- Base surfaces and text: deep blue and neutrals
- Recognition moments: gold
- Tiny signal details only: purple

## Practical Rules

- Keep a clear margin around the logo equal to one outer arrow width.
- Do not alter logo proportions.
- Avoid placing the logo over busy patterns.
- If a layout feels crowded, reduce secondary compass detail before shrinking the logo.

## Fast Checklist

- [ ] Correct logo variant selected
- [ ] Deep blue and gold are visually dominant
- [ ] Purple used as accent only
- [ ] Category names match official list
- [ ] Brand guide reviewed before final export

## Competition Telemetry Add-On (Copilot Only)

To collect prompt/token usage automatically in contestant projects:

1. Open `templates/copilot-submission-kit/INSTALL.md`.
2. Copy `templates/copilot-submission-kit/root/.vscode/tasks.json` to contestant repo `.vscode/tasks.json`.
3. Copy `templates/copilot-submission-kit/root/.github/copilot-usage/generate-copilot-usage-report.ps1` to contestant repo `.github/copilot-usage/generate-copilot-usage-report.ps1`.
4. Contestants then use Copilot normally; report files are generated automatically on folder open.

Generated files in contestant repo:

- `.github/copilot-usage/usage-summary.json`
- `COPILOT_USAGE_REPORT.md`
